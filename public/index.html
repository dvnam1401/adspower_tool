YouTube Data API v3 (Tổng Hợp Video Theo Profile)

Chưa cấu hình

Workflow "YouTube: Tổng Hợp Video Theo Profile" đọc Channel ID trong từng profile rồi gọi YouTube Data API v3 để lấy toàn bộ video (link, tên, thời gian đăng, lượt view) và xuất ra 1 file Excel duy nhất. Chỉ đọc dữ liệu công khai nên dùng API Key, không cần OAuth. Quota mặc định 10.000 units/ngày.

Google Cloud Console → APIs & Services → bật "YouTube Data API v3" → Credentials → Create API Key. Key lưu trên máy và KHÔNG bao giờ được trả lại giao diện.
